# 信创适配摸底（v1.1）

政务采购常见信创要求：麒麟/统信 OS + 国产 CPU（鲲鹏/飞腾/龙芯/海光）+ 国产数据库（人大金仓 KingbaseES / 达梦 DM8）。本文盘点本系统的适配面与迁移工作量。

## 结论先行

- **应用层零风险**：Java 21（毕昇/龙芯 JDK 可用）+ Spring Boot + Vue 纯标准技术栈，OS/CPU 层面无适配点；前端产物为静态文件。
- **数据库层为唯一适配面**，工作量集中在 PostgreSQL 方言（见下）。**首选人大金仓 KingbaseES**（PG 血统，V8R6 兼容模式下方言基本原样可用，预估 1-2 天验证）；达梦 DM8（Oracle 血统）需改写方言，预估 4-6 天。

## PG 方言使用清单（grep 实测）

| 方言 | 处数 | 金仓兼容性 | 达梦改法 |
|---|---|---|---|
| `insert … on conflict do update/nothing` | 9 | ✅ 原生支持 | 改 MERGE INTO |
| `… returning` （biz_seq 原子取号等） | 3 | ✅ | 改为 SELECT 后 UPDATE（需加锁）或序列 |
| `ilike` 模糊检索 | 3 | ✅ | `upper(col) like upper(?)` |
| `generate_series(1,12)`（月报） | 1 | ✅ | 改 12 行常量表或程序内循环 |
| `bytea` 附件 | 3 列 | ✅（同名类型） | BLOB |
| `::int/::date/::numeric` 强转 | 10 | ✅ | CAST(x AS type) |
| `bigserial` / `timestamptz` | 全部主键/时间列 | ✅ | IDENTITY / TIMESTAMP WITH TIME ZONE |
| Flyway | V1-V9 | ✅（kingbase 方言包） | 社区 dm 支持，需验证 |

## 建议路径

1. **摸底验证（1 天）**：金仓提供 Docker 镜像，把 Flyway V1-V9 全量跑一遍 + `mvn test`（改 JDBC URL 与驱动）+ E2E 90 步——本系统的 E2E 覆盖恰好是最好的迁移验收工具。
2. JDBC 驱动与 URL 参数化：`application-pilot.yml` 已环境变量化，加一组 `YBCASE_DB_DRIVER` 即可切换。
3. 若采购方指定达梦：按上表逐项改写（集中在 BizSeqService、BureauStatsController 月报、审计/检索 3 处 ilike），排期 4-6 天含回归。
4. 中间件替代面：无 Redis/MQ 依赖，Tomcat 内嵌（东方通/宝兰德替换属可选项，Spring Boot 支持外置容器部署）。

## 尚未验证项（诚实声明）

- 未在真实金仓/达梦实例上跑过（本文为静态盘点）；采购要求明确后按路径 1 用 E2E 做实测验收。
- 国产 OS 上的字体（卷宗打印 SimSun）需确认已装中文字体包。
