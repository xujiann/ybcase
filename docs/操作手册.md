## 一件案子怎么走（普通程序）

1. **线索管理**：登记线索（或"监控疑点导入"批量）→ 15 个工作日内核查（督办看板盯超期）→ 立案 / 不予立案 / 移送。
2. **立案**：从线索点"立案"，选案由（按当事人类别过滤）、关联执法事项（文书自动带法律依据）、填违法行为终了日（超时效系统阻断）、办案人员 ≥2 人（须在执法证台账内且未过期）。
3. **调查**：案件详情页录证据（八/九类）、笔录（可"模板生成"）、先行登记保存（7 日处理）、封存（30 日）；需鉴定评审用"期限扣除"或"专家评审"（自动扣除）。当事人对证据"质证"（辽宁口径下未质证不能作决定依据）。
4. **调查终结** → 填终结报告（六项内容）。
5. **告知**：填拟罚款/拟追回，系统按当事人类别自动判听证权利并载明陈述申辩期限；当事人陈述申辩/申请听证在"陈述申辩/听证"里记录；听证走"安排听证"（≥7 日前通知、主持人非办案人员）→ 举行 → 2 日内听证意见。
6. **法制审核**：提交审核（辽宁口径=全案必审）→ 法制岗办理（办案人员不能审）；未通过整改后再次提交。
7. **决定**：达"较大数额"须先录集体讨论（并签字确认）；填裁量理由（可先看"裁量基准建议"）；金额不得高于告知金额。
8. **送达**：登记送达回证（签收日=送达日）；电子送达须先签确认书（辽宁口径决定书禁电子送达）；简易程序另点"简易程序备案"。
9. **执行**：登记罚款/退回基金/没收（当场收缴须票据号且限额内）；逾期用"加处罚款测算"；困难户走"批准暂缓/分期"+分期计划；拒不履行"申请法院强制执行"。
10. **结案**：执行完毕/法院受理/无须执行 → 填结案报告 → 自动生成案卷号；"案卷目录"查装订顺序与文书齐全性；决定 7 日内"公开"，重大处罚"备案登记"。

## 日常监督

- **督办看板**：线索/审核/办案期限/送达/登记保存/封存/听证意见/简易备案/协查/责令改正/分期/公开/政府备案 十三类超期预警。
- **行政检查**：建检查任务（≥2 人）→ 登记结果 → 发现违法一键转线索。
- **举报奖励**：线索查实立案后登记 → 审批 → 发放。
- **统计分析**：驾驶舱 + 月报 CSV 导出 + 处罚决定公示脱敏导出。

## 管理员维护

- **参数设置**：全部期限/限额/阈值；国家↔辽宁口径切换（或运行 `python tools/init-bureau.py --province liaoning ...`）。
- **节假日表**：每年初按国办通知维护（影响一切"工作日"计算）。
- **执法证台账**：人员换证/停用；**案由字典**：法规更新时增补；**委托档案**：委托书须公布。
- **备份**：`tools/db-backup.ps1` 挂任务计划每日执行，保留 30 份；恢复命令见脚本注释。

## 生产部署要点

```bash
java -jar server/target/ybcase-server-*.jar --spring.profiles.active=pilot
```
须设环境变量：`YBCASE_DB_URL / YBCASE_DB_USER / YBCASE_DB_PASSWORD / YBCASE_JWT_SECRET`（强随机 ≥48 字符）。
上线检查单：改默认口令 → 初始化工具跑机构参数与人员 → 节假日表 → 裁量基准换正式文件 → 法律依据库按正式文本校核 → 备份任务计划。
