## 机构分类维护

在「系统管理 → 机构管理」按「处室」「分局」「医保中心」筛选，支持按机构名称或编码搜索。分类旁显示机构数量，包含启用和停用机构。「目录分组」保留上级组织结构，「待归类」保留原有未分类机构，医保中心各核查部的上级单位在表格中显示。

管理员点击「新增机构」，填写名称、编码，选择三类之一，并维护上级机构、职责及排序。编辑已有机构时保留原分类和上级关系；账号所属单位及账号类别仍在「用户管理」维护。

## 一件案子怎么走（普通程序）

1. **线索管理**：登记线索（或"监控疑点导入"批量）→ 15 个工作日内核查（督办看板盯超期）→ 立案 / 不予立案 / 移送。
2. **立案**：从线索点"立案"，选案由（按当事人类别过滤）、关联执法事项（文书自动带法律依据）、填违法行为终了日（超时效系统阻断）、办案人员 ≥2 人（须在执法证台账内且未过期）。
3. **调查**：案件详情页录证据（八/九类）、笔录（可"模板生成"）、先行登记保存（7 日处理）、封存（30 日）；需鉴定评审用"期限扣除"或"专家评审"（自动扣除）。当事人对证据"质证"（辽宁口径下未质证不能作决定依据）。
4. **调查终结** → 填终结报告（六项内容）。
5. **告知**：填拟罚款/拟追回，系统按当事人类别自动判听证权利并载明陈述申辩期限；当事人陈述申辩/申请听证在"陈述申辩/听证"里记录；听证走"安排听证"（≥7 日前通知、主持人非办案人员）→ 举行 → 2 日内听证意见。
6. **法制审核**：提交审核（辽宁口径=全案必审）→ 法制岗办理（办案人员不能审）；未通过整改后再次提交。
7. **决定**：达"较大数额"须先录集体讨论（并签字确认）；填裁量理由（可先看"裁量基准建议"）；金额不得高于告知金额。
8. **送达**：登记送达回证（签收日=送达日）；电子送达须先签确认书（辽宁口径决定书禁电子送达）；简易程序另点"简易程序备案"。
9. **执行**：登记罚款/退回基金/没收（当场收缴须票据号且限额内）；逾期用"加处罚款测算"；困难户走"批准暂缓/分期"+分期计划；拒不履行"申请法院强制执行"。
10. **结案**：执行完毕/法院受理/无须执行 → 填结案报告 → 自动生成案卷号；"案卷目录"查装订顺序与文书齐全性；决定 7 日内"公开"，重大处罚"备案登记"。

## 日常监督

- **督办看板**：线索/审核/办案期限/送达/登记保存/封存/听证意见/简易备案/协查/责令改正/分期/公开/政府备案 十六类法定时限预警（含决定后的公开/备案/分期与执行阶段的缴款逾期/催告/强执申请期）。
- **行政检查**：建检查任务（≥2 人）→ 登记结果 → 发现违法一键转线索。
- **举报奖励**：线索查实立案后登记 → 审批 → 发放。
- **统计分析**：驾驶舱 + 月报 CSV 导出 + 处罚决定公示脱敏导出。

## 管理员维护

- **参数设置**：全部期限/限额/阈值；国家↔辽宁口径切换（或运行 `python tools/init-bureau.py --province liaoning ...`）。
- **节假日表**：每年 11 月国办通知发布后，用页面上的「按年批量录入」粘贴全年安排（每行 `日期,放假/调休上班,名称`），**调休上班日必须录**。未录入时该页与督办看板顶部会持续红条提示（次年从 11 月起）。
- **执法证台账**：人员换证/停用；**案由字典**：法规更新时增补；**委托档案**：委托书须公布。
- **备份**：生产环境为 `/opt/ybcase/backup.sh`（crontab 每日 03:30，库与 FILE 模式附件各保留 14 份）；恢复与回滚步骤见 deploy/上线清单.md「日常运维」。`tools/db-backup.ps1` 仅用于开发机 WSL 库。

## 生产部署要点

```bash
# 完整环境变量：YBCASE_DB_URL/USER/PASSWORD、YBCASE_JWT_SECRET（必填，拒绝默认值）、YBCASE_ADMIN_INIT_PASSWORD（空库首启必填）、YBCASE_LOG_FILE（默认 /app/data/logs/ybcase.log，容器外须显式指定）、YBCASE_DB_POOL(10)、YBCASE_TOMCAT_THREADS(50)、YBCASE_JWT_EXPIRY_HOURS(12)、YBCASE_TIMEZONE(Asia/Shanghai)、YBCASE_MAX_FILE_SIZE(210MB)、YBCASE_SWAGGER(false)
java -jar server/target/ybcase-server-*.jar --spring.profiles.active=pilot
```
须设环境变量：`YBCASE_DB_URL / YBCASE_DB_USER / YBCASE_DB_PASSWORD / YBCASE_JWT_SECRET`（强随机 ≥48 字符）。

# v1.1 增补（正式化能力）

- **文书**：系统管理→文书模板可直接改模板（旧版自动入历史）；文书操作列新增 签章/验签/送达；"打印卷宗"一键合成封面+卷内目录+全部文书（含签章标记、页码）成册打印。
- **签章**：当前为 Mock 摘要签章（防篡改校验可用，无法律效力）；实施期替换 SignatureProvider 为政务 CA 实现即切换，业务零改动。
- **审批**：办案人员用案件页"提交审批申请"（立案/延期/中止/终止/暂缓），负责人在"待办审批"批准即自动执行、驳回须写理由——凡批准必有单。负责人直接操作原按钮时系统自动补记"直接批准"单据。
- **送达**：告知书等任意文书可在文书列表登记送达与回证；电子送达仍须先签确认书。
- **附件**：分"扫描件/执法音像/其他"；参数 attachment_storage=FILE 时走外置目录（音像限 200MB），生产建议 FILE+独立盘。
- **协同**：决定后可"移交经办处理"（约谈/暂停协议/解除协议/拒付/追回）并登记办理结果；司法移送登记受案回执（行刑衔接）。
- **检索**：顶栏全局搜索（案号/案名/当事人/线索）；案件列表分页+关键词。
- **审计查询**：在「参数设置」点击「查询审计日志」，可按操作时间、操作人、路径、请求号或报表类型筛选。报表导出记录显示统计日期区间、截至日和导出行数。业务统计页显示最近一次成功导出的请求号，可用该号码定位对应记录。参数设置页也可按月导出审计日志 CSV 归档。
- **处罚报表缺项**：局机关授权人员在「业务统计」选择年度和日期后点击「核对报表缺项」，查看同一批处罚决定的缺项。按案号查阅原案卷，在当前允许办理的节点录入经核实的资料，已决定或归档案件使用下述历史报表补录流程。无法核实的资料按原记录列示。
- **历史报表补录（V45）**：已决定、已送达或已结案的处罚案件，在案件页「历史报表缺项补录」提交缺项、补录理由和材料出处。另一名局机关法制或负责人在案件页或统计页核实并审核。批准后供处罚报表、执法人员报表和缺项清单取数。原案件、决定及案卷按原文保存，申请和审核记录可查询。
- **下一步待办（V46）**：行政工作台和经办页面新增统一待办。按当前岗位、机构及来源状态显示案件阶段、审批、法审、交接、经办反馈和补录审核等事项。按「进入办理」或「查看列表」回到原办理页面，事项状态更新后刷新待办即可看到变化。
- **实际约谈联动（V46）**：经办约谈已落实时，回复中填写实际日期、类型、事由、内容和参与人员，一并形成约谈台账。历史已回复事项可点击「登记实际约谈」补登记。机构名称来自原案件，机构编码可沿用已登记资料或核实后填写。同一经办事项只关联一条实际约谈，关联记录在约谈台账中保留来源。
- **经办到期提醒（V46）**：现有工作日早8点提醒任务会标记临期、超期经办事项，并向有效的案件承办人发送进度提示。经办待办显示「系统提醒」日期，人工催办日期单独保留。已回复、已退回及接收机构停用的事项退出本次到期提醒范围。
- **运维工具**：tools/upgrade-drill.ps1 带数据升级演练（发版前必跑）；tools/loadtest.py 压测（v1.1 实测 8 线程 328.9 RPS / P95 37ms / 0 错误）；信创迁移见 docs/信创适配摸底.md。
