# 三迭代功能使用说明

本说明覆盖补查与事实版本、约谈纠错、报表退回、后续材料补充卷、送达恢复、历史参办授权和运行保障。实际上线版本及验收结果以本次发布记录为准。原案件、原决定、原卷和已保存的报表文件继续保留，法律结论与实际办理事实由有权人员核实、批准。

## 账号办理就绪

局机关统计分析页显示账号办理就绪提示。所属机构待归类、类别冲突、证件或资格未核实等事项会显示具体原因。先由管理员对照真实名册维护机构、类别和岗位，再使用相应业务入口。

未归类机构的局机关账号可能仍有原有导出权限，但不因此取得事实更正或冻结报表复核资格。机构或账号停用后，原登录可能直接失效，需要联系管理员核实。不能通过反复刷新或增加管理员岗位替代业务复核资格。

## 基层办理补查与事实更正

### 法审退回补查

1. 在案件详情查看最新法制审核意见。最新意见要求继续调查、更改或纠正且符合当前条件时，在“调查补查与当前有效事实”点击“按法审意见退回补查”。
2. 填写补查理由和原始材料出处。系统保留原报告、原告知和原审核意见，案件回到调查阶段。
3. 完成补查，重新提交调查终结报告及确认的违法期间、事实、金额。随后重新办理必要的告知、申辩听证和法制审核。
4. 在已告知状态可点击“再次告知”，核对前次内容和变更理由。原告知不删除；旧审核不能替代变化后应完成的审核。

### 机构信息填错

调查阶段可在“调查补查与当前有效事实”点击“更正已填机构资料”，核对机构编码、性质、等级和类型，填写理由及材料出处。系统逐项留存更正记录。

决定后的机构信息或认定事实需要更正时，使用“执行续办与救济结果”中的独立事实更正申请，交另一名已归类局机关法制或负责人复核。原卷字段不回写。页面分别展示原卷信息和当前有效事实。

### 救济结果改变认定事实

按原有步骤登记受理及结果材料。变更结果确实改变违法期间、认定事实或认定金额时，按材料填写完整的适用事实组；与独立决定版本一并复核。报表按业务截至日和取数时已批准的信息使用有效版本，未来生效或未批准的资料不能提前入表。

## 实际约谈纠错

普通处室和医保中心来源的实际约谈统一走更正或误建作废申请。核对原日期、机构、人员和内容，填写新值、理由及材料出处，交另一名有权局机关法制或负责人复核。

批准前继续使用原有效记录，批准后新报表使用新的有效记录或排除已批准作废项。原约谈及协议关联保留，不另造重复约谈，不通过原编辑接口覆盖历史。若已上报，另生成更正重报批次并核对差异。

## 局机关核对三张报表

行政处罚、执法人员办理案件情况和约谈台账的原有导出入口仍在“统计分析”。日常数据取数、冻结预览、另一人确认、更正重报和原样下载继续使用。

新增错误退出操作：

| 情形 | 操作 | 结果 |
| --- | --- | --- |
| 生成者发现类型或期间选错，尚未确认 | 撤回并填写理由 | 保留文件及来源，退出待确认任务 |
| 另一名复核人发现待确认版本有误 | 退回并说明问题 | 原批次保留，生成者另行生成正确版本 |
| 有依据判定批次无效 | 按当前资格办理作废并留说明 | 保留原文件和处理记录，终态不能再确认 |
| 已确认后发生真实业务更正 | 更正重报 | 新批次关联前版，旧文件保持原字节 |

撤回、退回、作废不代表删除报表或撤销已经实际完成的外部报送。外部报送的更正手续由业务处室核实办理。

## 归档后材料与补充卷

### 基层建立材料包

1. 打开已有决定的案件，在“归档后续材料与补充卷”点击“建立材料包”，填写名称和材料出处。
2. 上传真实原件，每份不超过10MB，每包最多20份、合计32MB。需要纠正误传内容时，在提交前核对；提交后原件和清单不能替换。
3. 点击“提交复核”。另一名有权局机关人员会收到材料复核待办，可直接定位相应材料包。
4. 复核人下载原件、核对清单后批准或退回。申请人不能自审；待处理材料可由申请人撤回并保留记录。

### 绑定续办申请

提交执行续记、退款、冲正或结果等独立申请时，可选择已批准的同案材料包。申请保存该材料清单摘要，复核时再次核对。

同一申请的重试不能换掉或撤掉已绑定材料。已经处理的旧申请原本没有材料包时，也不能通过重放请求事后追加绑定。需要新增真实材料时，另按相应后续事项办理。

### 后续文书与实际送达

材料包批准后可“制作后续文书”。决定类后续文书必须关联具体已批准结果版本，正文与该版本一致，不能另写一份不同正文冒充同一版本。

签章入口会显示模拟或正式性质。实际纸质送达登记方式、日期、受送达人、回证号及出处。需要电子送达时，先在该后续文书中核实独立确认书及同意地址，再建立发送记录，在同案“电子送达与回证”中核对处理。

归档案件的独立后续文书可以继续办理，原卷保持封存。新回证关联具体后续文书，不把原案件改回在办状态，也不往原卷插入回证。

### 导出补充卷

已批准材料包可以“导出补充卷”，获得 ZIP，包含原始材料、材料清单及摘要、本包后续文书、签章和送达记录，以及已保存的原始电子回证。后续时间轴独立显示材料、复核、文书及续办过程。

补充卷与原卷分别保存。补充卷导出反映当前已登记的独立后续资料，不能把它冒充此前已封存的原卷或原冻结报表。

## 电子送达异常恢复

未封卷案件的历史同意标记为真但缺少结构化地址时，可在案件详情“核实或变更同意地址”，依据真实确认书补登。旧自由文本不会自动推测地址。

草稿、失败或超时发送需要换地址或重新建立轮次时，先人工核对供应商实际结果，再点击“核查换轮次”，填写核查结论和替代理由。系统保留旧记录，建立新待发送轮次，不自动发送。

已在途、已签收等记录不能直接替换。旧失效轮次的后续回执保留拒绝证据，不能污染新轮次。当前已有生效独立结果版本时，不能继续发送原决定或将其旧签收回执写入原卷。

原始回证可下载并核对摘要。正式模式要求相应正式签章及原始回证证据；模拟模式记录保持模拟性质，不能因切换模式升级为正式记录。

## 管理员核对历史参办授权

仅用于原参办记录当时未关联账号、后来已核实有效证号和正式账号的历史情形。不要按姓名批量授权。

1. 在原案件详情核对案号、证号和回避情况。管理员可查看用于核对的案件记录号、参办记录号。
2. 在用户管理进入历史参办授权核对，填写所核定的来源记录及目标登录账号，点击“核对授权条件”。
3. 查看权威预览，核对当前机构、证号、有效期及岗位，填写批准理由和原卷依据后明确批准。来源或账号变化后旧预览失效，须重新核对。
4. 核对错误时，在本案授权记录中填写收回理由及依据，明确收回该次授权。原批准记录和收回记录均保留，不停用其他案件所用的账号或证件来代替单案收回。

该功能保存独立访问授权，不修改原参办行、原卷或账号岗位；账号、机构、证件、回避等当前条件仍约束实际访问。

## 运维与正式接入

完整备份集、健康告警、受控发布、加密外拷、独立恢复和容量工具见[发布与恢复操作说明](/C:/Users/drxuj/Projects/医保案件/deploy/发布与恢复操作说明.md)。新备份工具安装后需正常运行一次备份，建立可核验的完整集合。

正式名册、真实执法资格、2027年工作日历、正式业务口径与供应商资料仍由局方落实。当前没有真实供应商和异地主机资料时，已交付能力通过模拟及隔离环境验收，不能据此记作真实财政、CA、电子送达或异地灾备已经验收。
